# Rutas del Proyecto

## Páginas Públicas

| Ruta | Descripción |
|-----|-------------|
| `/` | Entrada principal - Redirección hacia Luma Estate OS |
| `/luma-estate-os` | Landing principal del sistema |
| `/luma-estate-os/diagnostico` | Formulario de diagnóstico comercial |
| `/luma-estate-os/vista-del-rio` | Caso de estudio: Vista del Río |
| `/luma-estate-os/gracias` | Página de confirmación post-formulario |

## API

| Ruta | Descripción |
|-----|-------------|
| `/api/luma-leads` | Endpoint para captura de leads B2B |

## Notas

- Todas las rutas son compatibles con SSR y Static Export
- El formulario de diagnóstico guarda en Google Sheets configurado
- Las variables públicas permiten cambiar dominio sin modificar código
